03 · STITCHING & INNOVATIONS

中间模块缝合方式与自主创新点

模块缝合（Multi-Module Stitching）
1. COPE (CVPR'26) + SapiensID (CVPR'25) + Lab 部位色
Sapiens 缺失时自动回退至独立校准 COPE，叠加中央上下身 Lab 分布。
2. 静态外观 B + 时序顺序 H 对数几率融合 (I / J)
以 0.65 H + 0.35 B 融合对数几率，缺失连续片段时平滑回退静态模型。
3. 11 通道异构双向 Top-K 融合召回 (R)
串联 A/B/C、F/G/H/I、COPE、Sapiens 与 DTW 十一路通道并集。
4. LR + HistGradientBoosting + 视觉大模型 (N + VLM)
双模型反馈挖掘 + 统一主键表接入视觉大模型全量交叉复核。
自主创新（Custom Innovations）
1. 局部连续扩展门控 + 躯干脚踝偏移校准
IoU>0.5 / Δfoot≤0.35H / overlap>0.3 截断；脚部遮挡由躯干与框底偏移推算。
2. 整段反向增强膨胀 TCN + 反向单调 DTW
冻结 COPE 拼接帧差/Δt/运动输入 d=1,2,4 TCN；允许整段反向对齐。
3. 拒绝边全局分配 + 只排优先级 LR 排序器
引入「不配对」虚拟边与替代差距 Margin；高召回排序器绝不删减候选。
4. 短停留 (<30s) 二分图占位机制
先让 <30s 配对占据冲突端点阻断错配，一对一消歧后统一剔除。
