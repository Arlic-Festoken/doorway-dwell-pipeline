MODULE 1 · DETECTION & ENDPOINT CONSTRUCTION

模块 1 · 检测与端点构建

模块 1 细节拆解
1. 多检测器互补（缝合）
YOLO11-Pose 判定过线脚点；在密集漏检窗口调用 DEIM (CVPR'25) 与 CrowdDet (CVPR'20) 补框与确认双侧状态。
2. 局部连续扩展门控（创新）
从锚点前后扩展 ≤6s；严格校验相邻 IoU、脚点位移与同帧重叠，跨断轨入口两段分开保留不强拼。
3. 脚踝偏移校准与 PTS 统一（创新）
利用同段可见脚踝估计框底偏移回推进店帧；全流程统一原视频 PTS + 设备时钟偏移。

MODULE 2 · STATIC APPEARANCE MATCHING

模块 2 · 静态外观匹配（A–E, K）

特征与校准（A / B / C）
A · 多视角与 COPE 回退
取最多 3 组不重复清晰视图比对；缺失 Sapiens 时切独立校准 COPE。
B · 上下身 Lab 部位颜色
补充上/下身中央区域 Lab 色彩分布直方图（无 SCHP 分割依赖）。
C · 无泄漏场景适配
以较长连续轨迹采样正例、同帧空间分离行人采样负例重新拟合分类器。
全局分配与变体（D / E / K）
带拒绝选项的二分图优化
放弃「双向互为第一」硬约束，保留双向前 20 并集求解全局最大对数几率。
全局替代差距（Alternative Margin）
禁选当前边后重求解次优得分，D/E 阶梯放宽 (0.90/0.15 → 0.75/0.05 → 0.50/0.01)。
K · 同行辅助与短时返回
引入同帧同行行人上下文辅助；短时返回仅由共享清晰连续帧支持。

模块 3 · 时序顺序建模（F–J）

参考文献映射
GLTR (ICCV 2019)

AP3D (ECCV 2020)
借鉴相邻帧外观演化思想，输入相邻帧特征差与框形变化。
自研时序机制
连续片段非重叠拆分监督
同轨前后半段作正样本，同帧分离行人作负样本，反向增强训练。
正反双向 + 半片段推理
保留正向/整段反向与首尾状态聚合，不做乱序全局平均池化。
F–J 五方案分工
F（对照）/ G（TCN）/ H（联合）
F 用同批连续帧做静态对照；G 单用 TCN+部位；H 融合静态+TCN+DTW。
I / J（新旧对数几率融合）
0.65 H + 0.35 B 融合；I 阈值 0.75/0.05，J 放宽至 0.50/0.01。

MODULE 5 · UNIFICATION, VERIFICATION & FILTERING

模块 5 · 归并封装、交叉复核与筛选

模块 5 细节拆解
1. 主键去重与证据共享（缝合）
以 Ixxxx_Oyyyy 合并所有方法行并保留来源血缘；按端点共享图片/视频，模型任务屏蔽排序分。
2. 三值交叉复核协议（创新）
0 异人 / 1 同人 / 2 存疑（不作负例），新入口加填「进店动作成立」；跨轮分歧显式保留，结合 Grok 全量核对。
3. 短停留占位 + 一对一消歧导出（创新）
<30s 先占位防错配后剔除；每端点至多归属 1 次到访，按编号回填导出三列终表（进入 / 出店 / 停留时间）。
